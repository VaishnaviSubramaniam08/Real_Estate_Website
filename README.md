# WealthHome - Real Estate Website

WealthHome is a modern, responsive real estate website designed to help users find their dream homes. It features property listings, renovation services, and a contact system.

## 🚀 Features

- **Hero Section**: A welcoming interface with search functionality for property type, location, and intent (Buy/Rent).
- **Property Listings**: Detailed cards showcasing available properties with price, location, and key specs (beds, baths, square footage).
- **Renovation Services**: Dedicated sections for Quality and Historic home renovations.
- **Video Showcase**: Integrated video container for property tours and promotional content.
- **Contact Form**: A clean and functional contact section for inquiries and site visits.
- **Responsive Navigation**: Modern navbar with links to Home, About, Services, and Contact.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure for web content.
- **CSS3**: Custom styling with Flexbox and Grid layouts.
- **Font Awesome**: Professional icons for a modern look.
- **Google Fonts**: Clean typography for better readability.
